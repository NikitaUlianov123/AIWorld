Learning on a slippery floor

The mouse does not know the rules. A Q-learning agent tries moves, gets rewards, and slowly learns which action is best in each cell. Moves are not reliable: 80% go where intended, 10% slip to each side. Arrows show the current best action.

Tic-Tac-Toe with bad aim

Each square has a chance to hit: corners 50%, edges 100%, center only 25%. A miss places nothing and you lose your turn, but your next attempt always hits. The AI uses expectimax: it averages over every possible hit and miss and plays the move with the best expected result.

Numbers in the bottom corner of each square are the expected score of that move for the player whose turn it is, from −1 (sure loss) to +1 (sure win).

StoryTime

A word-level Markov chain from Markov_Chain/StoryTime.cs. For each word it records the next four words in the text. To write, it picks a random successor of the last word, again and again.

Architecture

One loop, any agent, any world

Agents never touch the game directly. An AgentRunner asks the environment for legal actions, the agent picks one, and the environment rolls the dice on the result. That is why every agent above can plug into every environment.

Ask for actions

The runner calls environment.GetActions(id) to get every legal Akshun.

Agent decides

agent.Move(actions) returns one action. Search agents follow a pre-planned path; learners pick from their model.

World resolves

environment.MakeMove(move, id) samples one Successor by its Chance.

Agent observes

The result goes back to the agent as its new CurrentGameState, an ISensorReading.

public interface IAgent<T> where T : ISensorReading
{
    List<T> Visited { get; }
    IFrontier<T> Frontier { get; }
    T CurrentGameState { get; set; }
    Akshun<T> Move(List<Akshun<T>> actions);
}

public interface IEnvironment<TSensors>
{
    void AddAgent(int ID, TSensors state);
    List<Akshun<TSensors>> GetActions(int agentID);
    TSensors MakeMove(Akshun<TSensors> move, int agentID);
}

Run it locally

Clone and play

You need the .NET 8 SDK. The Cheese Puzzle uses WinForms, so it runs on Windows only. You can also open AIWorld.sln in Visual Studio and choose a startup project.

# get the code
git clone https://github.com/NikitaUlianov123/AIWorld.git
cd AIWorld

# expectimax plays chancy tic-tac-toe
dotnet run --project TicTacChance

# A* solves the 8 puzzle (MonoGame window)
dotnet run --project 8PuzzleGame

# Q-learning mouse (Windows)
dotnet run --project CheesePuzzle
