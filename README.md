This is an AI playground, intended for experimenting with different types of AI in different challenges.  
It includes a fully modular system of Agents and Environments, making it very easy to experiment with.  


Currently implemented agents:
* Pathfinding algos: (Searching through states of the environment to get a path to the solution)  
  * Breadth First Search  
  * Depth First Search  
  * A-Star
* Bogo Agent (makes random moves, used as a control)  
* ExpectiMax  
* Markov Agent  
* Q-Learning

Currently implemented enviroments:
* 8 Puzzle
* Cheese puzzle (Grid enviroment with agent controlling a "mouse", and trying to reach the goal (cheese) while avoiding obstacles.)
* Chancy Tic-Tac-Toe (Different squares have different chances of "missing" your move, meaning the piece doesn't get placed and you lose your turn.)
